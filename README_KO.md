# 고요한 미술관 v1.3 — 무료 안드로이드 24시간 명화 갤러리

## 아시아 미술관 확장
다음 5곳의 회화 컬렉션을 Wikimedia Commons 공개 이미지의 **미술관별 분류**로 조회합니다. 공식 미술관 API에 직접 접속하는 방식은 아닙니다.
- 국립중앙박물관(한국)
- 도쿄국립박물관(일본)
- 교토국립박물관(일본)
- 나라국립박물관(일본)
- 국립고궁박물원(대만)

이전의 클리블랜드·시카고·메트로폴리탄 API 3곳도 유지합니다. 메트로폴리탄의 Asian Art 부서도 아시아 회화 후보에 포함합니다. 아시아 회화는 서양 13개 미술사조 뒤에 별도 구간으로 순환합니다. 해당 구간의 적격 그림이 부족하면 건너뛰며 출처·사조를 임의로 꾸며내지 않습니다.

## 이미지 필터
그림 종류는 회화·드로잉·판화 등 평면 작품입니다. 위키미디어에서 파일별 사용 조건을 확인하여 CC0 또는 퍼블릭 도메인인 JPEG·PNG·WebP만 채택합니다. CC BY나 CC BY-SA처럼 추가 의무가 있는 라이선스는 현재 제외합니다. 미술관별 Commons 분류에는 촬영 사진이나 분류 오류가 있을 수 있으므로 **액자/전시실 사진의 완전한 자동 제외는 보장되지 않습니다.**

## 전시/저장
- 30초 자동 전환, 세로 70%·비세로 30% 목표, 원본 비율 유지
- 최근 90일 중복 방지 및 매일 오전 10시(KST) 작품 목록 자동 보충
- 하단에는 작품명·작가명만 표시, 설정에서 화면 180도 회전
- Android 이미지 캐시 상한 100MB, 초과 시 80MB까지 정리
- 감상 기록과 이미지 파일 별도 저장, CSV 백업·복원 제공
- 유료 API/결제수단 없음. Wi-Fi·전기료는 별도

## 설치 및 주의사항
v1.3 앱 ID는 `com.gallery.kiosk.v13`이며 기존 v1.2와 **별도로 설치**됩니다. 기존 앱의 설정에서 감상 기록을 CSV로 백업하고 v1.3에서 복원한 다음 새 앱을 사용하세요. 백업 전 v1.2를 제거하지 마세요.

APK는 `Actions → Build Gallery APK`에서 GitHub Actions 빌드 후 Artifacts를 내려받을 수 있습니다. APK 컴파일과 내부 테스트가 성공하더라도 실제 Android 기기의 미술관 이미지 수신·장시간 안정성은 별도 현장 검증이 필요합니다.

## 검증
`node --test tests/*.test.cjs`로 소스·권리·중복 방지 테스트를 실행합니다. 실시간 Commons API 조회는 별도 `Verify Asian Museum Sources` 워크플로에서 조사합니다. 이 검사는 90일치 작품 확보나 전체 파일의 이미지 품질/권리 보장을 의미하지 않습니다.
