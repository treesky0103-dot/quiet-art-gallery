# 《고요한 미술관》 · 1800년 이후 80% 및 전 세계 미술 아카이브 확장 연구 보고서

기준: 2026년 11월 14일(KST) · 연구 분기: `feat-1800plus-80pct-global-archives-20261114`.

## 요청 및 목표

- 17개 미술사조 전부 표시 의무 해제.
- 사진·애니메이션 제외한 평면 미술(회화·드로잉·판화 등) 중심.
- 30초마다 작품 한 점. 90일 동안 작품 재사용 금지.
- 총 259,200개 중 **1800~2026년 제작 207,360개(80%)**. 나머지 **51,840개(20%)**.
- 세로 화면에서 원본 비율 유지, 75% 이상 채움, 짧은 변 1000px 이상, 긴 변 1400px 이상.
- 무료, 결제수단 등록 불필요 방식 우선. 저작권·개별 이용 조건 확인.

## 실제 수정

1. `web/core.js` 및 동일한 Android v1.6.6 연구용 자산에 작품 제작 연도의 숫자 범위(`yearStart/yearEnd`) 기반 `artworkEra`, `targetPost1800` (5회 중 4회) 및 90일 목표 수치 추가.
2. `web/app.js`에서 작품 선택 시 17개 미술사조 순서를 강제하지 않도록 변경, 제작 연대 미상 작품을 임의의 유파로 표시하지 않음.
3. 표시된 작품 중 실제 1800년 이후 작품의 비율을 설정 화면에 노출. 작품 부족 시 80% 실현 보장은 하지 않으며 실제 비율을 표시.
4. `web/index.html`의 35% 현대 디지털 미술 목표를 1800년 이후 80%로 변경. Android v1.6.6 연구용 사본과 웹 사본 바이트 일치.
5. `scripts/discover_world_art_archives.py`: 위키미디어 회화 관련 분류·위키데이터 미술관 공식 사이트·공개 API 안내를 통합 조사하고 후보 등록부 생성.
6. `scripts/collect_1800plus_80pct_pilot.py`: 미술관 제작 연도·공개 이용·평면 작품 여부·실제 이미지 다운로드·디코딩·화면 점유율·SHA-256·근접 중복 검사.

**주의: 해당 GitHub 소스는 기존 v1.6.6 기반 연구 분기입니다. 실제 갤럭시 탭 A7의 v1.7.2 APK, 이미지 재고, 재생 기록은 변경하지 않았습니다.**
